## Penjelasan SOLID

S - Single Responsibility Principle
Satu kelas harus punya satu alasan untuk berubah

O - Open/Closed Principle
Kelas harus open untuk extention, closed untuk modification

L - Liskov Substitution Princile
*Subclass* harus bisa menggantikan

I - Interface Segregation Principle (ISP)
*Client* tidak harus *depend* pada *interface* yang tidak gigunakan

D - Dependency Inversion Principle
Bergantung pada Abstraksi, bukan pada konkret
